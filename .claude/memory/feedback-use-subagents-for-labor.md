Mid-session correction from the owner (2026-08-06): "you are doing too many things
directly. you should be using subagents as helpers. you are using too much of your own
context window."

**Why:** at Fable/deep effort the session's tokens and context are the scarcest resource.
Rationalizing inline grinding as "the brief would cost more than the labor" was judged
wrong by the owner even for coupled reference-surgery chains the session had fully
mapped — the map belongs IN the brief, not in more inline edits.

**How to apply:** the session keeps only the foreman floor (decomposition, DoD, judging
reports, git/release mutations, owner communication). Everything else — multi-file edit
chains, reference sweeps, gate-running verification — goes to builders/leads/reviewers
with curated briefs. When a chain feels "faster to just do", write the brief anyway.
