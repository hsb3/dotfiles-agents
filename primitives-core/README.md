# primitives-core

The **single canonical source copy** of every primitive. Edit primitives **here** — never in
`plugins/` (those are generated by the marketplace assembler,
[`../scripts/gen_marketplace.py`](../scripts/gen_marketplace.py)). This is a Claude-Code-only
distribution; the multi-vendor translation surface was dropped at the clean-room rebuild.

## The primitive types

| Dir | Primitive | Canonical form | Notes |
|---|---|---|---|
| `skills/<name>/` | **skill** | `SKILL.md` (+ optional `references/`, `scripts/`, `assets/`) | `SKILL.md` at the folder root. |
| `agents/<name>.md` | **agent** | one `.md` with frontmatter | one workflow-aware agent per bundle is encouraged (P4). |
| `hooks/<name>/` | **hook** | handler + config in the ratified hook-dir layout `hooks/<name>/hook.py` | Claude-Code-only; stdlib-only (no pip/npm deps). |

## Roster entry schema

Every entry in [`../primitives-core.yaml`](../primitives-core.yaml) carries these fields
(enforced by [`../scripts/check_roster.py`](../scripts/check_roster.py)):

| Field | Values | Notes |
|---|---|---|
| `id` | unique kebab-case name | |
| `type` | `skill` \| `agent` \| `mcp` \| `hook` | |
| `source` | repo-relative path | must exist on disk (drift guard) |
| `shelf` | `core` \| `toggle` | |
| `origin` | `authored` \| `sourced` | provenance; immutable per entry. `sourced` requires non-null `upstream` + `ref`. |
| `disposition` | `qualified` \| `grandfathered-pending-use` \| `demoted` \| `untriaged` | |
| `targets` | `[claude-code]` | Claude-Code-only distribution. |
| `plugins` | list of bundle ids | membership: which bundle(s) ship this primitive. |
| `requires` | optional capability/dependency words | `{hooks,local-mcp,hosted-mcp}` + `cli:<kebab>` / `env:<kebab>`. |

`primitives-core` holds **self-authored** primitives only (ADR 0015); third-party items are
recorded by reference in [`../externals.yaml`](../externals.yaml), never copied in.

## The regenerate + drift-guard invariant

Every generated artifact (the assembled `plugins/` trees, `.claude-plugin/marketplace.json`)
has a deterministic generator and a `--check` mode that rebuilds into a tempdir and diffs
against the committed copy, failing on drift. `make ci` runs the checks; **no generated file
is ever hand-edited** — change the source under `primitives-core/`, then `make build`.
