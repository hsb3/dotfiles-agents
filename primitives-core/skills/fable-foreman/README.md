# fable-foreman

Operating doctrine for running a Claude Fable session as a foreman: size the job on complexity ×
parallelizability, pick one of five delegation architectures (direct, scouts, flat fan-out,
Opus-led team, phased crews), keep the judgment layer — decomposition, definition of done,
verification, synthesis — with Fable, and push token-heavy execution down to cheaper agents.

See [`SKILL.md`](SKILL.md) for the doctrine and
[`references/lead-brief.md`](references/lead-brief.md) for the lead-agent brief template.

## Credit

The scouts pattern and the handoff-packet brief format were inspired by
[Builder.io](https://www.builder.io)'s `efficient-fable` skill (distributed via
`@agent-native/skills`). This skill is standalone — the ideas it borrows are incorporated
directly rather than referenced.
