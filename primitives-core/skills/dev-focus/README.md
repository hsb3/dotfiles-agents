# dev-focus

Keeps a work session anchored to what it set out to do. Two lightweight checks: a **focus
check** that re-anchors a session against its original goal and flags drift, and a **scope
review** that sorts a task list into MUST/DEFER/CUT — biased toward deferring or cutting
rather than letting everything default to essential. Both produce a short, scannable output.

## When it triggers

Use it for "focus check", "are we still on track", "am I drifting", "scope this", "scope
review", "run the scope hammer", "what should we cut", or "MUST/DEFER/CUT" — or whenever a
session has sprawled past its original goal and needs re-anchoring before more work lands.

## Install

```
claude plugin install code-desk@dotfiles-agents
```

Ships in the code-desk bundle (not standalone).
