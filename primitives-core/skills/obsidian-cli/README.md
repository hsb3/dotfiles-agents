# obsidian-cli

Command reference and scripting patterns for the official Obsidian CLI, the Obsidian
desktop app binary itself: reading, creating, and modifying notes, daily notes, full-text
search, links/backlinks, tags and frontmatter properties, plugin management, and template
insertion — plus shell patterns for JSON processing, batch automation, and CI integration.
Use it to automate a vault from the terminal instead of clicking through the Obsidian UI.

## When it triggers

Use it when asked about the Obsidian CLI, a command-line interface for Obsidian, automating
or scripting a vault, Obsidian terminal commands, or integrating an Obsidian vault with
external scripts or tools.

## Install

```
claude plugin install obsidian-toolkit@dotfiles-agents
claude plugin install solo-skills@dotfiles-agents
```

Ships in the `obsidian-toolkit` and `solo-skills` bundles. Requires the Obsidian desktop app
installed locally. For plugin-side automation instead of CLI scripting, see
`obsidian-api-basics`.
