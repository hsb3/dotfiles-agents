# claude-code-expertise

Expert map of Claude Code's extension surfaces — skills, subagents, hooks, commands, plugins,
marketplaces, MCP servers, and settings/permissions — for authoring and debugging extenders.

## When it triggers

Use it to decide which surface fits a need, to look up a surface's frontmatter or config
contract, to author or debug a skill, subagent, hook, command, or plugin, or to answer how any
Claude Code extension surface works. It is the *map* (which surface, which contract, what's
idiomatic) — it complements the official skill- and plugin-authoring builders rather than
duplicating them, and it does not itself scaffold or install anything.

## Install

```
claude plugin install solo-skills@dotfiles-agents
```

Ships in the `solo-skills` bundle.
