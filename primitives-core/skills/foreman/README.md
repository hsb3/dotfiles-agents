# foreman

Delegation doctrine for a session that takes on a substantial task: size the job, pick an
architecture, set the definition of done, delegate the labor, and personally verify the
result — so premium tokens go to judgment and verification, not file-reading.

## When it triggers

Use it when a session takes on a feature build, refactor, migration, audit, or multi-file
fix estimated at more than ~30 minutes of agent work, even if the user never says "foreman"
or "delegate". Also use it when the user asks how to split work across agents, mentions
crews, teams, or subagents, worries about token cost on a big job, or wants to pick a model
tier or a delegation architecture.

## Install

```
claude plugin install atelier@dotfiles-agents
```

Ships in the atelier bundle (not standalone) — it is the delegation doctrine the
bundle's other skills (layer-cycle, waves) build on.
