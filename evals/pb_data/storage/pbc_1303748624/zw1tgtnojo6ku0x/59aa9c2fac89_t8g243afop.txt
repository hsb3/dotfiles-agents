# Local Bookmark Vault

A zero-dependency, self-hosted bookmark manager that runs entirely on Python's standard library. No database, no npm install, no Docker — just a single command to start collecting and organizing your bookmarks.

## Why this exists

Browser bookmark sync services lock you into their ecosystem, require accounts, and often lack the flexibility to organize bookmarks the way you want. Cloud-based bookmark managers add complexity, subscription costs, and privacy concerns. Local Bookmark Vault solves this by giving you a simple, self-hosted alternative that you fully control — your bookmarks live in a single JSON file on your machine, and the entire app runs on tools you already have installed.

The problem it solves: you want to save and organize bookmarks without depending on browser vendors, cloud services, or installing a mountain of dependencies. You want something that starts instantly, runs locally, and gets out of your way.

## What you get today

**Near-turnkey wins:**
- **Zero dependencies:** Runs on Python 3.10+ stdlib only — no pip packages, no database setup, no build tooling
- **Instant start:** One command (`make serve`) and you're running at http://127.0.0.1:8000
- **Tag-based organization:** Add optional tags to bookmarks and filter by tag in the UI
- **Flat-file storage:** All bookmarks stored in a single human-readable `bookmarks.json` file
- **RESTful JSON API:** Simple HTTP endpoints (GET/POST/DELETE) for programmatic access
- **Vanilla JS frontend:** No framework bloat — just plain HTML, CSS, and JavaScript (no build step)
- **Tested core logic:** Unit tests for validation, filtering, and ID management (9 tests passing)

**What this is:**
A working reference implementation and starting point for a personal bookmark manager. It demonstrates how to build a complete web app with zero external dependencies. The UI is functional and clean, the API is straightforward, and the codebase is small enough to understand in an afternoon (under 250 lines of Python + JS combined).

**What it is not (yet):**
- No authentication or multi-user support — this is designed for single-user local access
- No import/export for browser bookmarks (though the JSON format is trivial to parse)
- No search functionality — tags are the only organization mechanism right now
- No pagination — will slow down with thousands of bookmarks
- No HTTPS or production hardening — meant for local development use
- Not a replacement for feature-rich bookmark managers like Raindrop.io or Linkding

If you need production-grade security, multi-user support, or advanced features, this is a head-start, not a finished product.

## Getting started

**Requirements:** Python 3.10 or newer (uses modern type hints like `str | None`).

1. Clone or download this repository
2. Start the server:
   ```bash
   make serve
   ```
   Or directly: `python3 server.py`
3. Open http://127.0.0.1:8000/ in your browser
4. Add bookmarks, tag them, filter them — your data saves automatically to `bookmarks.json`

**Run the tests:**
```bash
make test
```

**Change the port:** Set the `PORT` environment variable:
```bash
PORT=3000 python3 server.py
```

## API reference

All endpoints return JSON.

**GET /api/bookmarks**  
List all bookmarks, or filter by tag with `?tag=<tagname>`.

**POST /api/bookmarks**  
Add a bookmark. Body: `{"url": "https://...", "title": "...", "tag": "..." }` (tag optional).  
Returns the created bookmark with its assigned ID.

**DELETE /api/bookmarks/:id**  
Remove the bookmark with the given integer ID.  
Returns `{"removed": true}` or `{"removed": false}`.
