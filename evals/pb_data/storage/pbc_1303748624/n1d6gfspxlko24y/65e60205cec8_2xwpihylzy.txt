# Local Bookmark Vault

A zero-dependency, self-hosted bookmark manager that stores everything in a single JSON file.

## Why this exists

Browser bookmarks sync across devices, but they're locked into your browser's ecosystem and lack flexible organization. Third-party bookmark services require accounts, subscriptions, and trust that your data won't disappear or be mined. Local Bookmark Vault solves this by giving you a simple, self-hosted alternative that:

- Runs on your own machine — no external services, no signup, no cloud dependency
- Uses a plain JSON file as storage — human-readable, version-controllable, trivially backed up
- Requires zero setup — no database, no Docker, no framework installation
- Works with stdlib Python only — no `pip install`, no virtual environment, no dependency rot

## What you get today

**A working bookmark manager that runs in 3 seconds:**

```bash
git clone <this-repo>
cd local-bookmark-vault
make serve
# Open http://127.0.0.1:8000/
```

**Core features (all functional):**
- Add bookmarks with URL, title, and optional tag
- Filter bookmarks by tag
- Delete bookmarks
- Persistent storage in `bookmarks.json`
- Clean, minimal web interface (no JavaScript framework, no build step)
- Full test coverage with passing test suite (`make test`)

**What it is not (yet):**

- **Not multi-user** — single-instance, single-file, designed for personal use on one machine
- **Not networked** — binds to `127.0.0.1` only; no authentication, not intended for public exposure
- **No search** — filtering by tag only; no full-text search across titles/URLs
- **No import/export** — the JSON file is directly editable, but there's no built-in browser bookmark import
- **No edit-in-place** — you can delete and re-add, but there's no edit button for existing bookmarks
- **Minimal styling** — functional but plain; this is a utility, not a showcase

If you need any of the above, this is a head-start, not a finished product.

## How it works

**Architecture:**
- `server.py` — HTTP server using stdlib `http.server` (no Flask, no FastAPI)
  - Serves static files from `static/`
  - Provides JSON REST API (`GET`, `POST`, `DELETE` on `/api/bookmarks`)
  - Reads/writes `bookmarks.json` directly
- `lib.py` — pure bookmark logic, no I/O, 100% unit tested
- `static/` — vanilla HTML/CSS/JS frontend, no build step, no dependencies

**Data format (bookmarks.json):**

```json
[
  {
    "id": 1,
    "url": "https://docs.python.org/3/",
    "title": "Python docs",
    "tag": "reference"
  },
  {
    "id": 2,
    "url": "https://news.ycombinator.com/",
    "title": "Hacker News",
    "tag": "news"
  }
]
```

It's a flat array. You can edit it by hand, back it up with `git`, sync it with Dropbox, or just `cp` it. No migration scripts, no schema upgrades.

## Usage

**Start the server:**

```bash
make serve
# or: python3 server.py
```

Serves on `http://127.0.0.1:8000/` by default. Set `PORT` to use a different port:

```bash
PORT=3000 python3 server.py
```

**Run tests:**

```bash
make test
```

**Add your first bookmark:**

1. Open `http://127.0.0.1:8000/`
2. Fill in URL (required, must start with `http://` or `https://`)
3. Fill in title (required)
4. Optionally add a tag (e.g., `work`, `reference`, `news`)
5. Click "Add bookmark"

The bookmark appears immediately and is written to `bookmarks.json`.

**Filter and delete:**

- Use the "Filter by tag" dropdown to show only bookmarks with a specific tag
- Click "delete" next to any bookmark to remove it
- The JSON file updates immediately

## Requirements

- Python 3.10+ (uses type hints with `|` syntax)
- No external packages

That's it. If you have Python 3.10+, this runs out of the box.
