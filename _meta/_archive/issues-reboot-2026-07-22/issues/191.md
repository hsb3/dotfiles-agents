## What it is
A **mature, stalled full-stack hosted web app** — not a sketch. `apps/web` Next.js 16 + IBM Carbon + Monaco; `apps/api` FastAPI + Firestore on Cloud Run + Firebase Hosting, email/password auth, per-user data. 91 commits (Jan–Jun 2026), ~400 files, Playwright + Vitest, OpenSpec-driven. **Momentum stalled ~2026-06-26** mid "Chat Parity Sprint" (`dev/fufo-chat-parity`); the roadmap's last two items (LangChain/LangGraph targets, App Hosting deploy) never shipped.

## Overlap with dotfiles-agents
Same **problem** (curate → version → assemble primitives → compile to harnesses) and literally the **same two primary targets** (`claude_code`, `opencode`). Diverges on substrate: **Firestore DB records + a runtime REST build pipeline + hosted multi-user GUI** vs **git flat files + deterministic generators + drift guards + a CLI/CI plugin marketplace**. Opposite third-party policy: functionform **copies upstreams in with provenance + live sync**; dotfiles-agents records **by reference only** (ADR 0015).

## Recommendation: RETIRE the repo (archive) + cherry-pick 3 concepts as issues; do NOT merge the code.
1. Architecturally incompatible with MERGE — folding a Firestore/Cloud-Run/Next/FastAPI hosted product into a git-native, stdlib-only, zero-install file marketplace shares concepts, almost no substrate.
2. dotfiles-agents genuinely supersedes the primitive-**management** core (same targets, cleaner source-of-truth) and is the actively-maintained one.
3. The value is ideas, not code — they port as design borrowings far more cheaply than the app ports as code.

**Strongest counter:** it's the only **hosted multi-user GUI / product surface** Henry has ever built for this. If the real goal is ever a product *others use* (not a personal git-native marketplace), retiring throws that away → then **park, don't archive**.

## Borrowable concepts (file as follow-ups if accepted)
- **`github_sourcing.py` + `sync_status {up_to_date|behind|diverged|not_found}` model** — a **working reference impl of the unbuilt externals-freshness feature (#36 / #122)**. Extract before archiving if externals-sync is wanted soon.
- **Assembly/component schema** — ordered `(primitive, position, transform, condition, version_pin)` + inherited `parent_assembly_id`. A proven model if bundles ever need ordered/parameterized/version-pinned composition (today they're flat id lists).
- **`{{placeholder}}` variables** (global + per-assembly override) and **`design_spec` per-primitive rationale** — build-time parameterization + co-located "why", both absent here.
