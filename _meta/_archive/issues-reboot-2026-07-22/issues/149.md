## Body

_Proto-issue. **Target:** machine — dotfiles-agents repo (code-desk plugin, repo-meta-structure skill)._

**Context:** Filing this repo's loose desk docs (2026-07-20), four files fit no
taxonomy dir: `NOTES.md`, `builderio-gotchas.md`, `skills-setup.md`,
`plan-app-docker.md` — secret-free durable runbooks and how-to reference.

**Problem:** The repo-meta-structure taxonomy (`references/layout.md`) covers
`_archive/` (superseded), `briefings/` (dated readouts), `plans/` (planning
desk), `operations/` (runbooks **with secrets**, untracked), and `research/`
(live investigations). A secret-free runbook is none of these: it's durable
(not archive), settled (not research), undated reference (not a briefing),
and deliberately keeps secrets in Keychain (not operations). `docs/` fails
the audience-facing boundary — these carry machine-specific ops detail. The
standard's only named `_meta/` root files are `HANDOFF.md`, `README.md`,
`mise-en-place.yml`, so such docs end up loose at the desk root.

**Suggested fix:** Add a `reference/` (or `runbooks/`) row to the `_meta/`
taxonomy table + a checklist row, with the boundary stated: secret-free
durable runbooks/how-to whose audience is the desk (machine-specific detail),
vs. `operations/` (secrets, untracked) and `docs/` (audience-facing). Until
then this repo declares `_meta/reference/` in `mise-en-place.yml`
`required_folders`.

**Provenance:** session 5 (2026-07-20), filing pass on this repo's `_meta/`.
