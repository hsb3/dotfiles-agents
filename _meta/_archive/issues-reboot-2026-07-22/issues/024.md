## Body

> **Origin:** deferred deliverable D of #22 (test/QA). The unit/validation layer (#22 A-C) checks artifact SHAPES statically; this confirms a generated bundle actually LOADS in the target tool.

## Problem

#22 added correctness checks over `targets/` (shapes, determinism, secret hygiene) but never loads a bundle in the real tool -- a fragment can be schema-correct yet rejected by opencode/Claude Code at load. The tool CLIs expose non-interactive load/inspect commands (verified 2026-06-29 via `--help`), so this is concrete, not best-effort. It is intentionally OUT of the required CI lane because it needs the tools installed.

## Deliverables

- A -- `make smoke` target (NOT folded into `make ci`).
- B -- opencode checks (point its config/dirs at the generated bundle): `opencode debug config`, `opencode debug skill`, `opencode agent list` / `opencode debug agent <name>`, `opencode mcp list`.
- C -- Claude Code checks: `claude --mcp-config targets/claude-code/mcp/<name>.json`; `claude --plugin-dir targets/claude-code/plugins/<p>` + `claude plugin details <name>`.
- D -- CMA: validate `targets/claude-agents/agents/*.json` against `BetaManagedAgentsCreateAgentParams` from the pinned OpenAPI spec (schema-level, no network). Cite `CANON.md` CMA contract.

## Acceptance criteria

- [ ] `make smoke` runs every check whose tool is present and **skips (does not fail)** when a tool is absent, logging exactly what was skipped (no silent caps).
- [ ] With opencode installed, a deliberately corrupted opencode mcp fragment makes `make smoke` FAIL.
- [ ] `make smoke` is NOT part of `make ci` (the required lane stays zero-install).
- [ ] The CMA schema check flags an agent payload missing a required field.

## Dependencies & gates

- Depends on: #22 (merged) for the artifacts under test.
- `make ci` aggregate: does NOT fire -- `make smoke` is a separate opt-in target.
- `actionlint`/`yamllint`: fires only IF a CI workflow is added for an optional smoke lane (recommend keeping it local-only).
- Needs `opencode` and/or `claude` on PATH; checks skip-on-absent.

## Out of scope

- Putting `make smoke` in the required CI lane (it is environment-dependent by design).
- Network calls to the live CMA API (schema-level validation only).
