## What it is

A skill that drives the executive desk's decision workflow end-to-end — today the mechanics live only in one desk's local instructions and are not distributable:

- Draft a **proposed** decision with genuinely defensible options (recommendation first)
- Package a ruling batch for the owner (deck + interactive Q/A form with markdown answers export)
- Capture the ruling; flip to **accepted** the same session; propagate operative consequences
- Supersession/correction mechanics (append-only record; pointer callouts on amended decisions)
- Decision-number collision repair (renumber the later-filed doc)

## Constraints

- Identity-neutral (0013 item 9): no desk names, repo names, or people hardcoded; personalization comes from the `_knowledge/` profile data surface
- Complements (does not duplicate) the desk-standard plugin's `conventions-standard` reference — this skill *drives the workflow*; that skill *states the rules*. Cross-reference, don't restate.

## Acceptance criteria

- Ships as an `exec-desk` bundle member; roster `origin: authored`
- A session on a fresh desk can run propose → package → rule → accept without local instructions
- Neutrality lint green; `make ci` green
