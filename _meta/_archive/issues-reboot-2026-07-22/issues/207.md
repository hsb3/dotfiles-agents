Follow-up from #149 (closed via PR #206). This repo declared `_meta/reference/` as per-repo variance in `_meta/mise-en-place.yml` (secret-free durable runbooks/how-to, distinct from `operations/`/`research/`/`briefings/`/`docs/`) because the shared `repo-meta-structure` standard's taxonomy has no slot for it.

Promoting this to the standard itself (`primitives-core/skills/repo-meta-structure/references/layout.md` + its checklist) needs an **optional-folder** concept the standard currently lacks — every `_meta/` taxonomy row today is a required, machine-checkable `path-exists` checklist row (per PR #206's investigation), so a descriptive-only or optional row breaks the standard's own contract. Scope: design + add an optional-row type to `layout.md`/`checklist.md`, then migrate this repo's per-repo variance declaration to the shared slot.

Not urgent — the per-repo workaround in `_meta/mise-en-place.yml` fully resolves the gap for this repo.
