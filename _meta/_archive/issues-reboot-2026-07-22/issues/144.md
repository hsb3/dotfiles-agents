## Body

## Why

The marketplace now distributes 7 plugins (post-#134 restructure), but only the two desk bundles (`code-desk`, `exec-desk`) ship a README. Five distributed plugins have none: **foreman-kit, github-project-board, opencode-expertise, pptx-themes, private-fork**. There is also no in-repo inventory of what the marketplace offers — a consumer (or Henry) has to read `marketplace.json` raw.

## Deliverables

**D1 — Generated plugin inventory.** A repo-level inventory of every distributed plugin (name, kind — bundle / plugin / standalone skill —, version, one-line description, contents summary: skills/agents/hooks count or list, install command `claude plugin install <id>@dotfiles-agents`). Emitted by `gen_marketplace.py` (sole marketplace owner) as a generated artifact — either a `PLUGINS.md` or a clearly-marked generated section of the root README — with a drift guard in the existing check lanes (red-able: hand-edit → CI fails).

**D2 — README for every distributed plugin.** Author README sources for the five missing plugins in the established value/proof register (what you get, worked example, honest scope — match `code-desk`/`exec-desk`):
- `foreman-kit` — the delegation kit: foreman + handoff skills, scout/builder/reviewer/lead agents, 4 discipline hooks
- `github-project-board`, `private-fork`, `opencode-expertise`, `pptx-themes` — standalone one-skill plugins (README can be brief: what the skill does, when it triggers, install line)

**D3 — Coverage guard.** A check that every plugin in `marketplace.json` ships a `plugins/<id>/README.md` (red-able by removing one).

## Constraints (binding)

- Generated artifacts never hand-edited; `gen_marketplace.py` assembles READMEs from source files (extend the D8a bundle-README mechanism to plugin/standalone kinds).
- **The standalone wrappers are guarded byte-identical to their skill source** (`check_skill_catalog` / standalone-wrapper check). Adding a README into a wrapper dir must extend that guard's contract deliberately (e.g. wrapper = skill source + assembled README, README excluded from the byte-identity scope) — not weaken it.
- Identity neutrality per the entry-gate floor; the `author` manifest attribution exception stands. README bodies neutral.
- `make ci` green; all guards red-able.

## Acceptance criteria

1. All 7 `plugins/<id>/README.md` exist in the generated tree and regenerate zero-drift.
2. The inventory artifact lists exactly the marketplace lineup, regenerates zero-drift, and CI fails if either goes stale.
3. Standalone-wrapper byte-identity guard still red-able on a real source mutation.
4. `make ci` fully green.

## Provenance

Henry's ask 2026-07-18 (post-cutover). Desk fact-check on `main`@`44f643b3`: README present = code-desk, exec-desk; missing = the five above. Built by the desk-supervised native crew, one PR into `dev`; publish to `main` owner-gated.
