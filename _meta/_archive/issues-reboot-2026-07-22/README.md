# issues-reboot-2026-07-22 — pre-reboot GitHub snapshot

A complete snapshot of the repository's GitHub issue tracker taken 2026-07-22, immediately
before the issue-tracker reboot. Captures all 99 issues (with their comments), 30 labels,
and the board items of project #11 as they existed at that moment.

Files:

- `index.json` — all 99 issues (metadata + bodies).
- `labels.json` — the 30 labels.
- `board.json`, `board_projects_full.json` — project #11 board items and project metadata.
- `pinned.json` — pinned issues.
- `issues/` — one file per issue.
- `comments/` — one file per issue's comments.

Frozen archive: read-only provenance of the pre-reboot state, not a live reference.
