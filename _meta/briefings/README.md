# _meta/briefings — dated readouts

Canonical home for dated briefing decks and status readouts produced by this repo's
work (not the Desktop). Each briefing is a dated folder (`YYYY-MM-DD-slug/`) or file.
Project-portfolio and executive-facing briefings for this repo live on the executive
desk (`EXECUTIVE_DESK/Projects/dotfiles-agents-desk/_meta/briefings/`); this directory
holds briefings whose audience is the repo itself.
